# Class Timer

A simple, kid-friendly countdown timer for the classroom. Pick a time, press Start,
and watch the color ring shrink. Add a dog photo (it is remembered on the device),
turn on lofi music, and press Fullscreen for the projector.

Open it here: https://dsbuddy.github.io/class-timer/

## Music

Background music is "Public Domain Lofi" by HoliznaCC0, released under CC0 1.0
(public domain, no attribution required). Tracks are bundled in this repo.
